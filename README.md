# Portfolio — Moch. Salman Al Fariz

Website portofolio statis menggunakan HTML, CSS, dan JavaScript.

## Cara melihat website
1. Ekstrak folder ini.
2. Buka `index.html` dengan browser, atau gunakan ekstensi Live Server di VS Code.

## Cara hosting gratis dengan GitHub Pages
1. Buat repository GitHub baru, misalnya `portfolio`.
2. Upload isi folder ini (`index.html`, `styles.css`, `script.js`, `README.md`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment, lalu buka tautan yang muncul di bagian Pages.
